# Administrator Manual

## Managing System Users & RBAC
1. Navigate to **User Directory** (`/users`).
2. Click **Invite New User**.
3. Select role: `ADMIN`, `ANALYST`, or `VIEWER`.

## Viewing Audit Trails
Navigate to **Audit Log Stream** (`/audit-logs`) to review all user logins, uploaded media files, and system configuration updates with IP and timestamp data.
